## 二、项目背景

校园中常见闲置教材、电子产品、生活用品、运动用品等二手物品。学生之间存在二手交易需求，但如果只依赖聊天群或线下询问，信息容易分散，查找效率较低。

本项目围绕校园二手交易场景，设计并实现一个简单但完整的前端平台。平台用于展示二手商品、搜索筛选商品、查看商品详情、收藏商品、发布闲置商品和查看个人中心。项目重点体现 Vue3 前端框架技术的使用能力，而不是复杂后端业务。

## 三、需求分析

根据课程考查要求，本项目需要体现 Vue3 基础指令语法、组件化开发、Vue Router 页面切换和状态管理能力。

本项目实现范围如下：

1. 用户注册和登录。
2. 首页展示和导航。
3. 商品列表浏览。
4. 商品关键词搜索和分类筛选。
5. 商品详情查看。
6. 商品收藏和取消收藏。
7. 发布二手商品。
8. 个人中心展示收藏和发布记录。
9. 退出登录。

本项目不实现真实后端接口、数据库、在线支付、即时聊天、真实图片上传和管理员后台。所有数据采用本地模拟数据和 localStorage 保存。

## 四、技术选型

| 技术 | 作用 |
| --- | --- |
| Vue3 | 页面和组件开发 |
| Vite | 项目构建和开发服务器 |
| Vue Router | 页面路由切换 |
| Pinia | 全局状态管理 |
| localStorage | 本地数据持久化 |
| CSS3 | 页面布局和样式 |
| JavaScript | 业务逻辑和交互实现 |

选择 Vue3 和 Vite 的原因是项目结构清晰、启动速度快，适合课程项目开发。Vue Router 用于实现多页面切换，Pinia 用于管理用户、商品和收藏状态，localStorage 用于在无后端条件下保存本地数据。

## 五、系统架构设计

本项目采用单页应用架构。浏览器加载 Vue 应用后，页面切换由 Vue Router 完成，用户状态和商品状态由 Pinia 管理，关键数据同步保存到 localStorage。

项目主要目录如下：

```text
src/
  main.js
  App.vue
  router/
    index.js
  stores/
    userStore.js
    productStore.js
  data/
    products.js
  components/
    AppHeader.vue
    AppFooter.vue
    ProductCard.vue
    ProductFilter.vue
    EmptyState.vue
  views/
    HomeView.vue
    LoginView.vue
    RegisterView.vue
    ProductListView.vue
    ProductDetailView.vue
    PublishView.vue
    ProfileView.vue
  styles/
    base.css
```

架构说明：

1. `main.js` 创建 Vue 应用，并挂载 Pinia 和 Vue Router。
2. `App.vue` 负责公共页面结构，包含头部、主体和底部。
3. `router/index.js` 负责配置页面路由和登录权限控制。
4. `stores/userStore.js` 负责用户注册、登录、退出和收藏状态。
5. `stores/productStore.js` 负责商品列表、商品查询和商品发布。
6. `components` 目录存放复用组件。
7. `views` 目录存放页面级组件。

## 六、页面与功能设计

项目共实现 7 个主要页面。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 首页 | `/` | 展示平台介绍、分类入口和推荐商品 |
| 登录页 | `/login` | 用户登录 |
| 注册页 | `/register` | 用户注册 |
| 商品列表页 | `/products` | 商品浏览、搜索和筛选 |
| 商品详情页 | `/products/:id` | 商品详情展示和收藏 |
| 发布商品页 | `/publish` | 登录用户发布商品 |
| 个人中心页 | `/profile` | 查看收藏商品和已发布商品 |

### 1. 登录和注册

注册页面提供用户名、密码和确认密码输入。系统会检查用户名不能为空、密码不能为空、两次密码必须一致。注册成功后用户信息保存到 localStorage。

登录页面提供用户名和密码输入。系统会检查账号密码是否匹配，登录成功后保存当前用户状态并跳转到首页。

### 2. 商品浏览和搜索

商品列表页展示商品名称、价格、分类、成色、交易地点和描述。用户可以输入关键词搜索商品，也可以按分类筛选商品。没有匹配结果时显示空状态提示。

### 3. 商品详情和收藏

商品详情页展示商品完整信息，包括名称、价格、分类、成色、交易地点、描述、卖家和联系方式。登录用户可以收藏或取消收藏商品，未登录用户点击收藏时会提示先登录。

### 4. 发布商品

发布商品页面要求用户登录后访问。用户需要填写商品名称、价格、分类、成色、交易地点、联系方式和商品描述。提交成功后，新商品会加入商品列表，并通过 localStorage 保存。

### 5. 个人中心

个人中心展示当前登录用户名、收藏商品列表、已发布商品列表，并提供退出登录功能。未登录访问个人中心时会自动跳转到登录页。

## 七、组件设计

本项目使用组件化方式拆分页面功能。

| 组件 | 作用 |
| --- | --- |
| AppHeader | 公共头部和导航 |
| AppFooter | 公共底部 |
| ProductCard | 商品卡片展示 |
| ProductFilter | 搜索和分类筛选 |
| EmptyState | 空状态提示 |

组件拆分遵循简单原则，只抽取重复使用或职责明确的部分，不为只使用一次的简单区域创建额外抽象。

## 八、状态管理设计

项目使用 Pinia 管理全局状态。

`userStore` 管理内容：

1. 已注册用户列表。
2. 当前登录用户。
3. 收藏商品 id。
4. 注册、登录、退出登录。
5. 收藏和取消收藏。

`productStore` 管理内容：

1. 商品列表。
2. 初始商品数据。
3. 发布商品。
4. 根据 id 查询商品。
5. 根据关键词和分类搜索商品。

localStorage 使用的 key 包括：

| key | 内容 |
| --- | --- |
| campus_market_users | 注册用户列表 |
| campus_market_current_user | 当前登录用户 |
| campus_market_products | 商品列表 |

## 十一、项目总结

本项目完成了一个基于 Vue3 的校园二手交易平台前端系统。项目覆盖了课程要求中的 Vue3 基础语法、组件化开发、Vue Router 页面切换、Pinia 状态管理和页面交互。

项目实现了登录注册、商品浏览、搜索筛选、商品详情、收藏商品、发布商品、个人中心等完整流程。虽然没有接入真实后端和数据库，但通过 localStorage 模拟了数据保存，保证刷新页面后主要数据仍然可用。

## 十二、不足与改进方向

本项目仍有以下不足：

1. 当前数据保存在浏览器 localStorage 中，不适合多人同时使用。
2. 商品图片使用占位展示，没有真实上传功能。
3. 没有实现买卖双方即时沟通。
4. 没有实现管理员审核和商品下架功能。

后续可以扩展真实后端接口、数据库、图片上传、聊天功能和后台管理功能，使系统更加接近真实应用。
